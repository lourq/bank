# Учебная платёжная система на Go

Консольный проект для практики структур, методов, мап, слайсов и конкурентности в Go. Пользователи могут пополнять баланс, снимать деньги и переводить их друг другу. Результаты операций и ошибки выводятся в консоль.

## Запуск

Требуется Go 1.26.2 или новее. Из корня проекта:

```bash
go run .
```

Чтобы запустить определённую версию, переключись на соответствующую ветку, например:

```bash
git switch v4
go run .
```

## Версии

Каждая следующая ветка дополняет предыдущую:

| Ветка | Что добавлено |
| --- | --- |
| `v1` | Структура `User`, пополнение через `Deposit`, списание через `Withdraw`, вывод баланса через `ShowBalance` и проверка недостатка средств. |
| `v2` | `PaymentSystem`, мапа пользователей по ID, очередь транзакций, методы `AddUser`, `AddTransaction` и `ProcessingTransactions`. Проверка наличия отправителя и получателя перед переводом. |
| `v3` | Обработка транзакций из канала в горутине через `Worker`, ожидание завершения через `sync.WaitGroup`. Примеры успешных переводов, неизвестных пользователей и недостатка средств. |
| `v4` | `sync.Mutex` в `User`: защита операций `Deposit` и `Withdraw`, включая проверку баланса перед списанием. |
